# To-Do List

A small, browser-based task list built with HTML, CSS, and JavaScript.

## Features

- Add a non-empty task to the list.
- Mark a task as done.
- Delete a task from the list.
- Clear the current text field with the **Remove** button.

Tasks are held on the page and are not saved after a browser refresh.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Yusra12376/To-do-List.git
   cd To-do-List
   ```

2. Open `index.to do list.html` in a modern web browser. Keep the HTML, CSS, and JavaScript files together in the project folder. No package installation or build step is required.

## Project files

- `index.to do list.html` — page structure and task-list controls.
- `to do list.css` — page layout and styling.
- `to do list .js` — task creation, completion, deletion, and input clearing.
